# 认识 OpenGuardrail

面向 AI Agent 的开源操作护栏：定义检查、收集证据，在工具行动前核验决策。

## 为什么使用它

将一次操作的策略、检查结果和证据汇入同一份可追溯的评估记录。按资源绑定策略，让新 Run 选择合适的修订。执行工具在行动前核验，团队在事后追溯。

## 如何工作

1. **定义要求：** 发布策略，明确检查项和证据要求。
2. **提交评估：** Agent 或集成执行检查，提交观测结果。
3. **核验执行：** OpenGuardrail 记录 `ALLOW` 或 `DENY`，工具核验证据、有效期和业务权限后再执行。

先[下载原生包](../native-install.md)运行清理 Demo，或在 pi / DeepSeek Harness 中体验 [Agent 插件](../plugin-trial.md)。下载后在浏览器打开的本地清理 Demo 使用预定义 Runner，插件使用宿主中已登录的模型。
